# C++ Book Ordering System

## 📖 Project Overview

The **Book Ordering System** is a team-based academic project developed using C++. The system is designed to manage book ordering activities through different modules, including Customer, Staff, and Data Management.

This project demonstrates the application of fundamental C++ programming concepts, modular programming, and basic system development.

## 🛠️ Technologies Used

* **Programming Language:** C++
* **IDE:** Microsoft Visual Studio

## 👩‍💻 My Contributions

This was a team project completed with one teammate. My main responsibility was developing the **Customer Module**, which represented approximately 50% of my contribution to the project.

My responsibilities included:

* **Customer Module Development:** Implemented the customer-related functions and operations in C++.
* **Flowchart Design:** Created the flowchart to illustrate the logic and workflow of the Customer Module.
* **Testing:** Prepared test data and documented the corresponding program outputs to verify the module's functionality.
* **Structure Chart:** Collaborated with my teammate to prepare the system's structure chart.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the `.sln` solution file or the project file using Microsoft Visual Studio.
3. Ensure that the **Desktop development with C++** workload is installed.
4. Build the project in Visual Studio.
5. Run the program.

**Note:** Make sure all required text files are placed in the appropriate working directory before running the program, as the system may need these files to read or store data.
